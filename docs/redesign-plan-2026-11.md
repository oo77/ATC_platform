# Редизайн интерфейса ATC — план (2026-11)

Правило: **меняется только интерфейс**. API-вызовы, бизнес-логика, права на сервере — без изменений.
План собран по отчётам 4 аудиторов: дизайн-система, списки (фильтры/пагинация), страница группы, детальные страницы + безопасность UX.

## 1. Диагноз

| Проблема | Цифры |
|---|---|
| Нет единой системы | 19 разных стилей `<h1>`, 129 вариантов `input`, 5 разных пагинаций, 682 «сырых» `<button>` |
| Перегруз внимания | на вкладке «Слушатели» группы — 20 кнопок одновременно; 8 одинаковых кнопок документов |
| Фильтры съедают экран | карточка «Фильтры» на 2–3 строки + 4 KPI-карточки → первая строка таблицы ниже сгиба на 1080p |
| Нет памяти | после «Назад» из группы фильтры и страница теряются → рутина повторного ввода |
| Шумная типографика | `font-black` ×329, `text-[9px]/[10px]` ×325, CAPS-заголовки, «стеклянные» тени `shadow-2xl` |
| Сломанные токены | `hover:bg-opacity-90` (нет hover у кнопок), `bg-info` не определён (72 места), `animate-in` без плагина |
| Опасные действия | «Удалить» рядом с «Редактировать»; архивация показывает красную кнопку «Удалить»; 13 `window.confirm` |
| XSS | `CalendarView.vue` — подсказка события собирается через `innerHTML` без экранирования |

## 2. Принципы (дизайн + психология труда)

1. **Одно главное действие на экран.** Остальное — в меню «Документы ▾» / «Действия ▾» / «⋯». (Закон Хика: меньше равнозначных вариантов — быстрее решение.)
2. **Группировка по смыслу работы, а не по типу кнопки.** Документы группы сгруппированы по жизненному циклу обучения: Начало → Ход → Аттестация → Завершение.
3. **Состояние видно, не нужно помнить.** Активные фильтры — снимаемые «чипы» + «Сбросить всё»; счётчик «Найдено N».
4. **Опасное — отдельно и с трением.** Удаление — внизу меню, красным, после разделителя; для необратимого — ввод кода/названия.
5. **Плотно, но спокойно.** Контролы 36 px, шрифт Inter, веса 400/500/600, без CAPS и «стекла», один нейтральный цвет.
6. **Ничего не теряется.** Фильтры, страница и вкладка живут в URL → «Назад» возвращает ровно туда, где был.

## 3. Дизайн-система (фундамент)

- **Токены** (`app/assets/css/main.css`): шрифт Inter; `--font-weight-black` → 700, `extrabold` → 650 (глобально успокаивает 329 мест); добавлен `info-*`; кнопки с реальным hover.
- **Компоненты** (`app/components/ui/`, авто-импорт `<UiX>`):
  - `UiPageHeader` — хлебные крошки, заголовок, мета-строка, слот действий.
  - `UiFilterBar` — поиск (debounce, «/» — фокус, Esc — очистить) + быстрый сегмент + «Фильтры (n) ▾» (сворачиваемая панель) + чипы активных фильтров + «Найдено N».
  - `UiPagination` v2 — компактная, внутри карточки таблицы, лимит всегда в списке опций, `hideLimit`, мобильный режим.
  - `UiDropdown` — меню с группами, иконками, подписями, спиннером, danger-пунктами, клик-вне/Esc/клавиатура.
  - `UiTabs` — подчёркнутые вкладки со счётчиками.
  - `UiStat` — плоская метрика (полоса метрик вместо 5 «bento»-карточек).
  - `UiEmptyState`, `UiSensitiveValue` (маска + показать + копировать).
  - `UiConfirmModal` v2 — `requireText` (ввод для подтверждения), `loadingText`, блок закрытия во время операции, корректный вариант `warning`.
- **Лейаут**: спокойные сайдбар/шапка (без glass/blur-теней), без двойных отступов страниц.

## 4. Страницы

| Зона | Что делаем |
|---|---|
| **Группа** `groups/[id]` | Шапка в 1 строку: крошки · код + статус · мета (курс · даты · дни · слушатели). Справа ровно 3 контрола: **Сертификаты** (primary) · **Документы ▾** (8 форм по этапам) · **⋯** (Управление / Опасное). Полоса из 4 метрик. Вкладки со счётчиками; «Документы» → «Файлы». Убраны дубли дат/статуса/кода. Действия файлов видны всегда (не только при hover). |
| **Списки** (группы, слушатели, программы, сертификаты, организации, банк тестов, шаблоны, журнал действий, заявки, библиотека, представители) | `UiFilterBar` + `UiPagination` v2 внутри карточки; sticky-шапка таблицы; строки кликабельны; действия строки — 1 иконка + «⋯». |
| **Детальные** (слушатель, пользователь, преподаватель, программа, аттестация) | `UiPageHeader`; удаление/архив — в «⋯» или «Опасная зона» (по образцу аттестации); маскирование ПИНФЛ/паспорта. |
| **Безопасность UI** | экранирование подсказки календаря; `window.confirm` → `UiConfirmModal`; подтверждение для отзыва доступа/удаления преподавателя; права `canManageAttestation`/`canManageTestBanks` на кнопках. |

## 5. Вне рамок (требует изменения логики — отдельно)

- Перехват 401 → редирект на вход с баннером «Сессия истекла».
- `auth_token` читается из `document.cookie` в `downloadReport/previewReport` → cookie не httpOnly.
- `/environment` в PUBLIC_PAGES; пароль студента по умолчанию = ПИНФЛ; генератор паролей на `Math.random`.
- Отсутствующие записи `PAGE_PERMISSIONS` для `/users/[id]`, `/test-templates/[id]`.
